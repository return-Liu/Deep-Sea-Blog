
# Deep Sea 管理端

## 项目定位

Deep Sea 管理端是一套基于 Vue3 + TypeScript + Element Plus 构建的企业级后台管理系统，面向一刻时光博客平台提供全链路业务管理与用户数据运营能力。项目采用 Vite 构建工具、Pinia 状态管理、Vue Router 路由权限控制，严格遵循组件化、模块化工程规范，具备高可维护性与扩展性。

## 克隆项目

```bash
git clone https://github.com/return-Liu/Deep-Sea-blog.git
进入目录
bash
cd Deep-Sea-blog
安装依赖
bash
npm install -g pnpm
pnpm install
启动开发服务器
bash
pnpm run dev
打包构建
bash
pnpm run build
环境要求
Node.js v20.11.0 或更高版本

操作指南
登录操作
访问系统首页，选择密码登录或邮箱验证码登录

输入账号密码或验证码，完成极验验证码校验

点击登录按钮进入系统

内容管理操作
发布文章：进入内容管理 > 博客管理 > 新建文章，填写标题、正文、标签后发布

上传摄影：进入摄影管理 > 上传作品，选择图片文件，系统自动提取 EXIF 信息

管理留言：进入留言墙，可筛选分类、回复留言、处理举报

管理照片：进入照片墙，支持图片分类、上传编辑、分页浏览

用户管理操作
编辑资料：进入用户中心 > 个人资料，修改头像、昵称、个性签名等

安全设置：进入安全中心，修改密码、查看设备管理、注销账户

切换账号：支持同一设备下多账号快速切换

系统管理操作
冻结管理：查看账户冻结状态、原因及解冻倒计时

设备管理：查看登录设备列表，支持远程登出

举报中心：处理用户举报和反馈，跟踪处理结果

个性化设置
点击右上角设置图标，可切换日间/夜间主题、选择语言、自定义布局

核心功能模块
登录与安全体系
系统提供双模式认证机制，支持密码登录与邮箱验证码登录，集成极验验证码实现人机校验，并配备验证码倒计时防刷、登录失败次数限制及账户临时锁定策略。密码安全方面采用 MD5 加密存储，支持通过邮箱重置密码，并设计账户冻结页面，清晰展示冻结原因与解冻倒计时，形成完整的账户安全防护闭环。

工作台与智能助手
主页集成动态轮播、即时通讯聊天室（Vue + Node.js + WebSocket）、留言墙、照片墙及团队自研 Yike Design UI 框架展示区。智能助手模块接入科大讯飞星火深度推理模型 X1 大语言模型，支持全屏对话与深度思考模式（开发中），为用户提供智能化辅助体验。

内容管理中心
博客管理：支持文章创建、编辑、删除及标签分类

摄影管理：作品上传、EXIF 信息提取与展示

随笔随记：日常记录与个性化展示

留言墙：多样化背景、分类筛选、点赞评论及举报机制

照片墙：图片分类、上传编辑、分页浏览与在线预览

全局搜索
支持关键词检索与内容类型筛选（文章/摄影/随记），搜索结果关键词高亮显示，提升内容查找效率。

用户系统
个人资料：头像上传裁剪、昵称颜色自定义、性别地区生日设置、个性签名

安全中心：安全等级可视化评估、密码修改、设备管理、账户注销

多账号管理：同一设备特征码下支持多账号快速切换

系统管理
冻结管理：账户冻结状态展示、原因说明、解冻倒计时

设备管理：登录设备列表、详情查看、远程登出

举报中心：用户举报与反馈处理、结果跟踪

互动生态
支持多层级嵌套评论、表情包插入、个性化评论背景卡、点赞互动与举报机制，构建健康的社区互动环境。

资源管理
按年月分类浏览本地文件，支持文件详情查看与图片在线预览。

通知与更新
系统通知模块用于发布更新内容、功能介绍及账号切换提醒，保持用户与平台的信息同步。

个性化设置
主题切换：日间/夜间模式

多语言：中文/英文等多语言支持

布局自定义：界面布局灵活配置

技术特色
响应式设计：完美适配 PC 端与移动端

用户体验：完善的加载状态、错误边界与交互提示

安全保障：验证码校验、密码强度验证、账户冻结机制

工程化实践：组件化架构、模块化组织、类型安全（TypeScript）

项目价值
Deep Sea 管理端构建了一个集内容创作、社交互动、智能辅助、系统运营与安全防护于一体的完整生态平台，具备企业级项目的前端架构能力与全栈落地经验。
