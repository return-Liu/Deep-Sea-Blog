**Deep Sea 管理端**是基于 Vue3 + TypeScript + Element Plus 构建的全功能后台管理系统，用于管理一刻时光博客平台的核心业务数据与用户内容。项目采用 Vite 作为构建工具，Pinia 进行全局状态管理，Vue Router 实现路由权限控制，并严格按照组件化、模块化的工程规范进行开发。

**登录与认证体系**：支持密码登录与邮箱验证码登录双方式，集成极验验证码实现人机校验，具备验证码倒计时防刷机制、前端登录失败次数限制与账户临时锁定功能，支持通过邮箱重置密码，密码采用 MD5 加密存储，并提供账户冻结页面展示冻结原因与解冻倒计时。

**主页模块**：集成动态轮播展示、基于 Vue + Node.js + WebSocket 实现的即时通讯聊天室、支持留言发布与互动的留言墙、摄影作品展示的照片墙、团队自研 Yike Design UI 框架展示区，以及集成科大讯飞星火深度推理模型 X1 大语言模型的 AI 智能助手，支持全屏聊天模式和深度思考模式（开发中）。

**数据统计**：展示总访问量和今日访问量，并提供博客文章、摄影作品、随笔随记的快捷创建入口。

**内容管理**：包含博客文章的创建、编辑、删除及标签分类管理，摄影作品上传与 EXIF 信息展示，随笔随记的日常记录与个性化展示；留言墙支持多样化背景样式、分类筛选、点赞评论及举报功能；照片墙支持图片分类管理、上传编辑与分页浏览。

**全局搜索**：支持关键词搜索及按文章、摄影、随记等内容类型筛选，并实现搜索结果关键词高亮。

**用户系统**：提供个人资料编辑（头像上传与裁剪、昵称颜色自定义、性别地区生日设置、个性签名）、安全等级可视化评估、登录设备管理与远程登出、密码修改与账户注销、同一设备特征码下的多账号切换管理。

**系统管理**：包括账户冻结状态展示与解冻倒计时提醒、设备列表查看与详情展示、举报中心处理用户举报与反馈管理。

**互动功能**：支持多层级嵌套评论结构、评论表情包、个性化评论背景卡、点赞与举报机制。

**资源管理**：支持按年月分类浏览本地文件、查看文件详情及图片在线预览。

**系统通知**：用于查看系统更新内容与账号切换提醒。

**个性化设置**：支持日间/夜间主题模式切换、中英文等多语言支持及界面布局自定义。

**技术特点**：整个系统采用响应式设计适配 PC 与移动端，具备完善的加载状态、错误处理与友好提示，并集成了验证码校验、密码强度验证、账户冻结等安全机制，形成了一个集内容创作、社交互动、智能辅助、系统管理与安全防护于一体的完整博客管理生态。
